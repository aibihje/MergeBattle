课堂操作说明
  • 拖动卡片到草坪格子；或者先点一下卡片，再点格子（适合触屏白板）。
  • 先种声母豌豆，再把介母火炬花、韵母向日葵拖到它身上，拼成真正的音节才能融合。
  • 韵母卡下面的 ˉ ˊ ˇ ˋ 用来换声调；声调不对，阳光豆打不动字牌。
  • 植物发射的阳光豆只能净化举着同一个字的糊涂怪。点一下融合好的植物，会读出它的字。
  • 提示：第一次显示字牌拼音，第二次点亮要用的卡片。慢速适合低年级。用铲子可以铲掉种错的植物。
  • 快捷键：Space 暂停 · H 提示 · P 显示字牌拼音 · Esc 取消选中
  • 调速：点游戏右侧「调速」或标题页「速度」按钮，在 很慢 0.4× / 慢 0.6× / 稍慢 0.8× / 原速 1× 之间切换，糊涂怪和整体节奏一起变慢，设置会自动记住。
  • 自定义汉字：标题页或选关页点「自定义汉字」，输入本课生字即可自动转拼音、拆出声母 / 介母 / 韵母 / 整体认读，并生成专属关卡；点彩色拼音可切换多音字读音。自定义关卡每只糊涂怪都举汉字牌、随机出场，进关约 2 秒就来第一只怪。
